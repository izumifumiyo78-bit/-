## 概要

`PITCH 26` は、ライブラリもビルド工程も使わない素のJavaScript（ESモジュール）だけで
作られたサッカーゲームです。HTML5 Canvas 上に**3次元の実座標で試合を計算し、
透視投影でピッチ・ゴール・選手を描画**しているため、見た目は中継カメラそのものになります。

- 11人 vs 11人のフルマッチ（前後半・ハーフタイム・サイド交代）
- 回転（マグヌス力）・空気抵抗・バウンド・転がり抵抗まで再現したボール物理
- オフサイド / ファウル / カード / スローイン / CK / GK / FK / PK
- ポジショニング・プレス・オフザボールの動き・GKのセービングを行うAI
- タッチ操作（左スティック＋5ボタン）・キーボード・ゲームパッド対応
- PWA：ホーム画面に追加してワンタッチ全画面起動、オフラインでもプレイ可能
- チーム名・選手名・エンブレムはすべてオリジナル

## 遊びかた

### すぐ遊ぶ

静的ファイルだけなので、任意のHTTPサーバーで配信すれば動きます。

```bash
node tools/serve.mjs      # http://127.0.0.1:8099 で起動
```

ブラウザで開き、**クイックマッチ → チーム／フォーメーション／難易度を選択 → キックオフ**。

### スマホにインストール（ワンタッチ起動）

タイトル画面の「ホーム画面に追加」に手順が出ます。

| 端末 | 手順 |
| --- | --- |
| iPhone / iPad (Safari) | 共有ボタン → 「ホーム画面に追加」 → 「追加」 |
| Android (Chrome) | ⋮ メニュー → 「アプリをインストール」 |

追加後はアドレスバーなしの全画面・横向きで起動し、一度読み込めば**オフラインでも**遊べます。

## 操作

### タッチ（スマホ）

画面左半分のどこをドラッグしてもスティックが出ます（フローティングスティック）。
右側のボタンは**攻撃中と守備中でラベルと機能が切り替わります**。

| ボタン | 攻撃中 | 守備中 |
| --- | --- | --- |
| 青 | パス（長押しでロングパス） | 選手切替 |
| 赤 | シュート（長押しで強く／短押しで巻く） | タックル |
| 黄 | スルーパス | 味方をプレスに行かせる |
| 紫 | クロス | スライディング |
| 緑 | ダッシュ（押しっぱなし） | ダッシュ |

### キーボード / ゲームパッド

| 操作 | キー | パッド |
| --- | --- | --- |
| 移動 | WASD / 矢印 | 左スティック |
| パス | J / Space | A |
| シュート | K | X |
| スルーパス | L | Y |
| タックル・スライド | H | B |
| ダッシュ | Shift | RT / RB |
| 選手切替 | Q | LB |
| 一時停止 | Esc / P | Start |

スティックの入力は**カメラ基準**に変換されるため、どのカメラ角度でも「上＝前」です。

## 設計

```
src/
  core/      util.js      ベクトル・補間・決定論的乱数
             config.js    ピッチ寸法（FIFA規格）と全チューニング値
  data/      teams.js     16クラブ＋手続き生成のスカッド
             formations.js 6フォーメーション（正規化座標）
  sim/       ball.js      3Dボール物理（抗力・マグヌス・バウンド・ポスト）
             player.js    慣性のある移動、スタミナ、歩容、スライド、GKダイブ
             team.js      フォーメーションの「バネメッシュ」、守備ライン
             actions.js   パス／シュート／クロス／ヘッド／タックルの共通実装
             ai.js        役割割当・ボール保持者の判断・オフザボール・GK
             rules.js     競技規則とリスタート配置
             match.js     ワールド、フェーズ機械、接触解決、時計
  render/    camera.js    透視投影カメラ（画面サイズ対応・縦画面専用カメラ）
             renderer.js  スタジアム・芝・ライン・ゴール・選手・ボール
             hud.js       スコアボード・レーダー・メーター・タッチUI
             effects.js   パーティクル（芝・土煙・紙吹雪・ネットの揺れ）
  io/        input.js     タッチ／キーボード／ゲームパッド
             audio.js     Web Audio による効果音・歓声の合成（音声ファイルなし）
  game/      replay.js    リングバッファとリプレイカメラ
             ui.js        メニュー画面
  main.js                 起動・フレームループ
```

### 設計上のポイント

- **シミュレーションは DOM に一切触れません。** そのため Node から
  ヘッドレスで試合を回してバランス検証ができます（`tests/`）。
- **固定タイムステップ 60Hz** ＋アキュムレータ。描画が重くても挙動は変わりません。
- **パスの危険度は「時間」で評価します。** 直線上に相手がいるかではなく、
  *ボールより先に相手がそのコースへ到達できるか* を計算しているので、
  AIは本物らしくパスコースを選びます。
- **GKは全知ではありません。** 反応遅れ・読み違い・人間並みの横移動速度を持ち、
  リーチは3次元（浮かせたシュートはGKの手の高さを越えます）。
- **近接平面クリッピング**を自前で実装。カメラ背後に頂点が回る低いリプレイ
  アングルでもポリゴンが破綻しません。

## 開発用コマンド

```bash
node tools/serve.mjs            # ローカルサーバー
node tests/sim_match.mjs 4 5    # 前後半4分の試合を5本ヘッドレス実行して統計表示
node tests/user_mechanics.mjs   # シュート成功率・パス・タックルなどの計測
node tests/set_pieces.mjs       # 全リスタートが必ず再開するか検証
node tools/playtest.mjs         # 実ブラウザで自動プレイ（Playwright）
node tools/shots.mjs            # 各解像度のスクリーンショット
node tools/perf.mjs             # CPUスロットリング下のFPS計測
node tools/make_icons.py        # PWAアイコン生成
```

### 現在のバランス（前後半4分・プロ難易度・AI対AI 30試合平均）

| 指標 | 値 |
| --- | --- |
| 1試合の得点 | 約 4 点 |
| シュート | 約 19 本 |
| パス成功率 | 約 66% |
| ファウル | 約 8 |
| オフサイド | 約 1.3 |
| インプレー率 | 約 82% |

無人のシュート成功率は 8m で約50%、18m で約20%、26m で約13% と距離に応じて減衰します。
