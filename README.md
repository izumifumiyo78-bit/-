# PITCH 26 ULTRA

**ブラウザで動く超フォトリアル3Dサッカー**
画像・3Dモデルファイルを一切使わず、すべてをシェーダーとプロシージャル生成だけで描画

Vite + Three.js (WebGL2) / PWA / マルチタッチ / 高リフレッシュレート対応

</div>

---

## これは何か

`PITCH 26 ULTRA` は、**外部アセットを1バイトも読み込まない**サッカーゲームです。
芝も、革のボールも、ユニフォームの生地も、観客も、広告看板も、空も、
すべて実行時に数式とシェーダーで生成しています。

```
アセットファイル数: 0   (PWAアイコンを除く)
テクスチャ読み込み: 0   (番号と広告はCanvas2Dで実行時生成)
3Dモデル読み込み:   0   (選手・ボール・スタジアムは全てコード生成)
```

ゲーム部分（11人制フルマッチ、ボール物理、AI、審判）は固定ステップの
シミュレーションとして描画から完全に分離されており、**絵がどれだけ重くても
サッカーの挙動は一切変わりません**。

## 画づくり

### 芝（`src/gfx/pitch.js` / `grass.js` / `turfmap.js`）

| 要素 | 実装 |
| --- | --- |
| 草一本一本 | カメラ前方に最大15万本のインスタンス描画。風・踏み倒し・選手による押し退けを頂点シェーダーで計算 |
| 刈り込み模様 | 5mブロックのモザイク。**刈り方向に沿った異方性スペキュラ**（Filament方式のanisotropic GGX）で、TV中継と同じく見る角度で明暗が反転する |
| ライン | 全ラインをSDFで解析的に描画。`fwidth`で距離に応じてアンチエイリアス |
| スパイク跡・芝のめくれ | ピッチ空間のRTに毎フレーム蓄積（R:踏み倒し / G:土の露出 / B:水 / A:鮮度）。数分かけてゆっくり回復する |
| 摩耗 | ゴール前・センターサークル・PKスポットが試合前から擦り切れている |
| 朝露 / 濡れ | 高周波ハッシュによるグリント、濡れた芝の暗化と鏡面化 |
| 水たまり | 低地ノイズ＋リップル。**平面反射（Planar Reflection）**を基層に、ポストの**SSR**が近距離の接触反射を上乗せ |
| 芝の透過光 | 逆光時に葉を透過する緑の輝き（back-scatter） |

### ライティング（`src/gfx/shaderlib.js` / `env.js` / `lights.js`）

- 解析的な大気散乱スカイ（Rayleigh/Mie位相関数・2層のFBM雲・夜は星と天の川）。
  **同じ関数**を空・反射・フォグ・IBLが共有するので画面全体の辻褄が合う
- 太陽色はKasten-Young大気質量による光学的深さから計算（低い太陽角で自動的に赤くなる）
- GGX + Smith + Schlick、布は Charlie sheen + wrapped diffuse、肌はラップ拡散＋透過
- 影：three.jsのシャドウマップ（PCFSoft, 最大4096）＋**ポストのスクリーンスペース・コンタクトシャドウ**
- ナイター：4基の照明塔が**実光源**としてBRDFに入る。影の方向は夜だけ鉛直寄りに切り替わる
  （4基同時照明の見た目に近く、屋根の影がピッチに落ちる破綻も防げる）
- ボリューメトリックライト：**実際のシャドウマップをレイマーチ**して光芒を生成。
  屋根・照明塔・選手のオクルージョンがそのまま光芒に出る
- 照明塔のライトシャフト：加算合成の円錐＋3Dノイズのチリで湿った夜気を表現

### ポストプロセス（`src/gfx/post.js`）

ライブラリ不使用、全パス自前実装:

```
AIR   (1/2解像度) ボリューメトリック散乱 + コンタクトシャドウ（αに格納）
SSR   (1/2解像度) 濡れた地面のスクリーンスペース反射
BLOOM            しきい値 → 13タップ縮小×4 → テントフィルタ拡大×4
COMP             DOF（リングボケ）/ 再投影モーションブラー / レンズフレア
                 / ACES RRT+ODTフィット / lift-gamma-gain / 彩度
FINAL            FXAA / コントラスト適応シャープ / グレイン / 色収差 / ビネット / sRGB
```

### 選手とボール

- 選手は**15ドローコールで22人**。部位ごとにインスタンス描画し、骨の変換行列だけをCPUで更新
- アニメーションはクリップ無し。接地足の軌道を直接設計し、**2ボーンIK**で膝を解く。
  走り・キック（振り上げ→インパクト→フォロースルー）・スライディング・GKダイブ・
  ゴール後の歓喜まですべて手続き的
- キットは柄（縦縞/フープ/サッシュ/ハーフ/無地）・襟・パイピング・背番号をシェーダーで生成。
  織り目のノーマル、汗による濡れ、スライディングの泥、風によるはためき付き
- ボールは32パネルの切頂二十面体を**球面ボロノイ**で解析生成。シーム溝・ステッチ・革のグレイン・
  芝と泥の付着・濡れ・インパクト時の変形（接触軸方向につぶれる）
- ゴールネットは**Verlet布**。ボールが当たると波打ち、揺れが伝わって収まる

### スタジアム

- 丸めた長方形のスイープ1本からスタンド・階段・座席・屋根・トラスを生成
- 観客は最大3万人。1人2三角形のビルボードだが、シルエット・服・肌・髪・
  立ち上がり・ウェーブ・夜のフラッシュはすべてシェーダー内で決まる
- LED看板は実行時にCanvasで描いた広告をスクロール表示（得点時はストロボ）

npm install
npm run dev -- --host      # スマホから http://<PCのIP>:5173 で実機テスト

### スマホにインストール（ワンタッチ起動）

Android/Chrome なら「アプリをインストール」、iOS/Safari なら共有→「ホーム画面に追加」。
追加後は**アドレスバー無し・横画面フルスクリーン**で起動し、オフラインでも動きます
（`display: fullscreen`, `orientation: landscape`, Workboxによる完全プリキャッシュ）。

### 操作

| | タッチ | キーボード | パッド |
| --- | --- | --- | --- |
| 移動 | 画面左半分のフローティングスティック（360度） | WASD / 矢印 | 左スティック |
| パス | パス（守備時は選手切替） | J / Space | A |
| シュート | シュート（守備時はタックル） | K | X |
| スルー | スルーパス（守備時はプレス） | L | Y |

## パフォーマンス

- GPU名とデバイスメモリから3段階のティアを自動判定（ROG Phone 6のAdreno 730等は最上位）
- 実表示リフレッシュレートを起動時に実測し、165Hzなら120Hz上限で**可変フレームレート**動作
- フレーム時間を監視して**内部解像度を0.5〜1.0倍で自動調整**（UIはDOMなので常に等倍で綺麗）
- 設定から ULTRA / HIGH / PERFORMANCE を手動切り替え可能（草・SSR・ボリューメトリック・モーションブラーが段階的にオフ）

```bash
node tools/perf.mjs     # CPUスロットリング下のfpsと解像度スケール
node tools/shot.mjs     # 各時間帯のスクリーンショットとコンソールエラー検査
node tools/e2e.mjs      # メニュー→フルタイム→オフライン再起動まで通し
```
