操作方法

スマホ（タッチ）

  • 画面左をドラッグ：バーチャルスティックで移動
  • パス：味方へパス（長押しでロングパス）
  • シュート：長押しで強く、短押しで巻いたシュート
  • スルー：裏へ抜け出す味方へスルーパス
  • クロス：サイドからのクロス
  • ダッシュ：押し続けてスプリント
  • 守備時はボタンが切替／タックル／スライド／プレスに変化

キーボード

  • WASD / 矢印：移動
  • J / Space：パス　K：シュート
  • L：スルーパス　H：タックル/スライド
  • Shift：ダッシュ　Q：選手切替
  • Esc / P：一時停止

ゲームパッド

  • 左スティック：移動／A:パス X:シュート Y:スルー B:タックル RT:ダッシュ

ホーム画面に追加（ワンタッチ起動）

追加するとアドレスバーなしの全画面で起動し、オフラインでも遊べます。

iPhone / iPad（Safari）

  1. 下部の共有ボタン ⬆ をタップ
  2. 「ホーム画面に追加」を選択
  3. 「追加」をタップ
  4. ホーム画面のアイコンから起動（横向き推奨）

Android（Chrome）

  1. 右上の⋮ メニューをタップ
  2. 「アプリをインストール」／「ホーム画面に追加」
  3. 「インストール」をタップ
