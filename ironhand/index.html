IRONHAND

自分の手で剣を振る、剣と魔法の闘技場

遊び方を選ぶ

操作（PC）

剣（右手）Webカメラに右手を映して振る。グーで握るように構えると、刃は拳の人差し指側へ伸びます
魔法（左手）左手をグーにする（またはZL / F / スペース）と発動。火球は手を突き出して離すと飛びます
移動WASD / ジョイコンのスティック
視点画面をクリック後マウス / 左右キー / 右スティック
カメラなしの場合マウスで剣を動かす（ホイールで前後）、右ドラッグで視点、左クリックで魔法
その他Q 魔法切替 / R 武器切替 / Shift スロー / C 位置リセット / Esc ポーズ

操作（スマホVR）

  1. ジョイコンをスマホとBluetoothで接続（レール横の小さいボタンを長押し）
  2. 「戦いを始める」を押してから、スマホを横向きでゴーグルに入れる
  3. 背面カメラの穴がふさがっていないか確認。両手を目の前に出すと手が映ります
  4. 右手を振ると剣、左手をグー（またはZL）で魔法
  5. スティックで移動・右スティックで30°回転、−ボタンで正面リセット

VR酔いしたらすぐ休憩してください。周りに物や人がいない広い場所で遊んでください。
