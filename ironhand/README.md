# IRONHAND

自分の手で剣を振って戦う、剣と魔法の闘技場ゲーム（ブラウザで動作）。

- **PCモード**：Webカメラで両手を認識。右手を振ると剣、左手で魔法。カメラなしならマウスで操作
- **スマホVRモード**：スマホをVRゴーグルに入れて左右2画面表示。首の向きはジャイロ、手は背面カメラで認識
- **ジョイコン対応**：Bluetoothでつなぐと移動・魔法・武器切替などに使える（ボタン割り当て変更可）
- 敵はラグドール物理で崩れ落ち、強く斬ると首や手足が飛ぶ
- 魔法：火球（溜めて投げる）／雷撃（押している間放電）／念動（敵を掴んで投げ飛ばす）
- スローモーション、パリィ（敵の攻撃に剣を当てる）、3種の武器（剣・斧・槍）

## 起動

```bash
node tools/serve.mjs   # リポジトリのルートで実行
# → http://127.0.0.1:8099/ironhand/
```

スマホのカメラは **https** でないと使えません。GitHub Pages などに置いて https で開いてください。
（同じWi‑FiのPCから http で配信してもスマホではカメラが使えません）

## 操作

| | PC | ジョイコン |
| --- | --- | --- |
| 剣 | 右手を振る（カメラなし: マウス） | — |
| 魔法 | 左手をグー / F / スペース / 左クリック | ZL・ZR |
| 魔法切替 | Q | X・↑ |
| 武器切替 | R | Y・↓ |
| スロー | Shift | L・R |
| 移動 | WASD | スティック |
| 視点 | クリック後マウス / ←→ | 右スティック（VRは30°ずつ） |
| 正面リセット | C | − |
| ポーズ | Esc | + |
| 斬る（手の認識なし） | — | A・B |

## 構成

```
ironhand/
  index.html      メニューと設定
  js/main.js      起動・描画ループ（PCは1画面、VRは左右2画面）
  js/game.js      プレイヤー・武器・魔法・敵AI・ウェーブ・HUD・パーティクル
  js/body.js      敵の体（歩行・攻撃アニメ、Verletラグドール、部位切断）
  js/hands.js     MediaPipe Hand Landmarker → 3Dの手の位置と剣の向き
  js/input.js     ジョイコン / キーボード / マウス / ジャイロ
  js/world.js     闘技場
  js/audio.js     効果音（WebAudioで合成）
  lib/            three.js 0.170（MIT）、MediaPipe tasks-vision 0.10.35 と手のモデル（Apache-2.0）
```
